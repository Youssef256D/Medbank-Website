# Announcement — Google sign-in retired (2026-09-10)

Audience: the 779 people whose accounts were removed on 2026-09-10 (see
`docs/delete-google-users-runbook.md`).

**A one-time notice now sits on the login page** (shipped in `2026-09-10.02`)
telling anyone who lands there that Google sign-in is gone and they should sign
up again with the same email. It catches the people who try to log in on their
own. It does not replace the message below — someone who never opens the site
again will never see it.

**They cannot be reached in the app.** Their accounts no longer exist, so an
admin notification will not reach them and their push device tokens were deleted
with the account. Use email (all 779 addresses are in the exported roster) or the
student group. Everything below is ready to copy.

## Before you send

1. **Turn the hosted Google provider off first** (Supabase dashboard →
   Authentication → Providers → Google). The website already hides the buttons,
   but the Android app can still sign in with Google — and a student who does
   will land in a brand-new empty account instead of following these
   instructions, which makes the announcement look wrong.
2. **Send by email, in batches**, using the exported roster. 779 recipients in
   one To: field exposes every student's address to every other student — use
   BCC, or a mail-merge tool, or send in small batches.
3. **Expect a wave of approvals.** Every one of these people arrives unapproved.
   `student_auto_approval` is currently **off**, so each account needs a manual
   approve on the admin Users page. Turning that switch on before you send would
   approve complete signups automatically as they come in.
